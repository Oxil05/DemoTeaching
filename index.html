Processor

Central Processor (CPU)

  • Composed of the Control Unit (CU) and the Arithmetic and Logic Unit (ALU).
  • Reads & writes memory cell contents.
  • Forwards data between memory cells and special registers.
  • Decodes and executes program instructions.
Storage

Central Memory (RAM)

  • Group of semiconductor cells used for general processes & program execution.
  • Generically called Random Access Memory (RAM).
  • Volatile Nature: Integrated circuits lose stored information when electricity is interrupted.
Interfacing

I/O & Auxiliary Storage

  • I/O Units: Interfaces enabling communication between external world, processor, and memory.
  • Auxiliary Memory: Magnetic storage media holding files consisting of variable numbers of fixed-size registers.

III. LESSON PROPER • PART 3

Universal Logic Gates & Expression Synthesis

Understanding why NAND and NOR gates are universal building blocks for digital computer architecture.

⚡

Universal Functions

The NAND and NOR gates are called universal functions because either one of them can be used to generate all basic operations: AND, OR, and NOT.

Sum of Products (SOP)

A function in sum of products form can be implemented using NAND gates only by replacing all AND and OR gates with NAND gates.

Product of Sums (POS)

A function in product of sums form can be implemented using NOR gates only by replacing all AND and OR gates with NOR gates.

🛠️

NAND & NOR Equivalencies

NOT A ➔ A NAND A or (A • A)'
A AND B ➔ ((A • B)')' [NAND followed by NAND inverter]
A OR B ➔ (A' • B')' [Inputs inverted via NAND, then NANDed]
