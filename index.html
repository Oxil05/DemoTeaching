Architecture vs. Organization Concepts

Understanding the distinction between operational blueprints and physical hardware realization.

🏛️

Computer Architecture

The basic operational design of a computer system.

  • Pioneered by John Von Neumann, credited for most modern computers.
  • Visible to program developers & assembly instruction sets.
  • Example: The 80x86 processor family uses Von Neumann Architecture (VNA).
⚙️

Computer Organization

The physical interconnections of hardware units.

  • Promotes deep understanding of internal electronic components.
  • How system designers combine components directly impacts system performance.
  • Focuses on memory cells, control lines, and signal paths.

STAGE 4 OF 8 • LESSON PROPER

Core System Components Breakdown

Detailed characteristics of CPU, Central Memory, I/O Units, and Auxiliary Memory.

🧠

Processor & Central Memory

Central Processor (CPU)

Made of the Control Unit (CU) and Arithmetic Logic Unit (ALU). Reads/writes memory cells, forwards data, decodes and executes program instructions.

Central Memory (RAM)

Group of semiconductor cells used for program execution. Volatile Disadvantage: Integrated circuits lose stored info when electricity is interrupted.

💾

I/O & Auxiliary Memory

Input / Output Units (I/O)

Interfaces enabling processor communication with the exterior. Allows introducing information to be processed and later visualizing processed data.

Auxiliary Memory Units

Stored information on magnetic media receives the name of files. Files consist of fixed-size registers holding info or programs.

STAGE 7 OF 8 • LESSON PROPER

Universal Functions & Expression Synthesis

NAND and NOR gates are universal functions that can generate AND, OR, and NOT operations.

⚡

Universal Synthesis Rules

NAND and NOR can construct any digital circuit without using other gate types.

Sum of Products (SOP) Form

Can be implemented using NAND gates only by replacing all AND and OR gates with NAND gates.

Product of Sums (POS) Form

Can be implemented using NOR gates only by replacing all AND and OR gates with NOR gates.

🛠️

Gate Conversion Equivalencies

NOT A ➔ A NAND A or (A • A)'
A AND B ➔ ((A • B)')' [NAND + NAND Inverter]
A OR B ➔ (A' • B')' [Inverted Inputs NANDed]
